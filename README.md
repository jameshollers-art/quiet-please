# Quiet, Please

A cozy 3D librarian sim. Run the desk, shelve returns, shush the noisy and lock up on Friday night.

- `www/` – the game (`index.html`), its 3D library files (`vendor/`) and the app-only updater (`app.js`)
- `ios/` – the iPhone and iPad project
- `.github/workflows/` – cloud TestFlight builds and over-the-air game updates

**Start with [SETUP.md](SETUP.md).**
